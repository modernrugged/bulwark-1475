# Bulwark 1475 🏰

A retro SNES-style castle defense game built with modern web technologies.

## About

Bulwark 1475 is a tower defense game inspired by classic 16-bit era graphics and gameplay. Defend your medieval fortress against waves of enemies using strategic placement of defenses and resource management.

## Features

- Retro SNES-style pixel art graphics
- Classic castle defense gameplay mechanics
- Wave-based enemy progression
- Resource management system
- Multiple tower/defense types
- High score tracking

## Quick Start

### Local Development

1. Clone the repository:
```bash
git clone https://github.com/modernrugged/bulwark-1475.git
cd bulwark-1475
```

2. Serve the game locally:
```bash
# Using Python 3
python3 -m http.server 8000

# Or using Node.js
npx serve .

# Or using PHP
php -S localhost:8000
```

3. Open your browser to `http://localhost:8000`

## Game Controls

- **Arrow Keys**: Navigate menus / Move cursor
- **Space/Enter**: Select / Confirm
- **ESC**: Pause / Cancel

## Technology Stack

- HTML5 Canvas for rendering
- Vanilla JavaScript for game logic
- CSS3 for UI styling
- Web Audio API for retro sound effects
